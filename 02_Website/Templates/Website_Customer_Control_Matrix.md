# Website Customer Control Matrix

**Status:** Planning template  
**Last Updated:** 2026-09-09

## Purpose

Define what customers may safely control, what SLAI manages, and what requires custom work.

| Capability | Customer Self-Service | ServicesOS When Connected | SLAI Support | Custom Quote |
|---|---|---|---|---|
| Business name/contact | Yes | Yes | Yes | No |
| Hours/holiday hours | Yes | Yes | Yes | No |
| Services/prices | Yes | Yes | Yes | No |
| Staff public profiles | Yes | Yes | Yes | No |
| Logo/photos | Yes | Yes where supported | Yes | No |
| Colors | Yes, validated | Yes where supported | Yes | No |
| Approved fonts | Yes | Optional | Yes | No |
| Layout/theme | Yes, approved options | Optional | Yes | No |
| Page creation | Approved page types | Optional | Yes | Unsupported types only |
| Section order/variants | Yes, compatible options | Optional | Yes | Unsupported behavior |
| Navigation | Yes | Optional | Yes | Complex navigation |
| Preview/publish | Yes | Yes where integrated | Yes | No |
| Rollback | Yes where exposed | Optional | Yes | No |
| Custom component | No | No | No | Yes |
| Custom integration | No | No | No | Yes |
| Shared-core/security changes | No | No | Authorized SLAI only | Engineering scope |

## Rule

> Customers control their business identity and supported presentation choices. SLAI controls shared platform integrity.
