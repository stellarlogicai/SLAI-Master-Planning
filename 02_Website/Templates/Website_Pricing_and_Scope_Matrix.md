# Website Pricing and Scope Matrix

**Status:** Working hypothesis template  
**Last Updated:** 2026-09-09

## Purpose

Keep SLAI Web pricing tied to actual scope, support burden, and variable cost rather than arbitrary complexity.

| Path | Working Build Fee | Recurring | Intended Use |
|---|---:|---:|---|
| DIY | $0 | $100/mo | Customer uses guided onboarding/dashboard and builds within approved system |
| Done-for-you | ~$750-$1,000 | $100/mo | SLAI configures standard approved layout/sections and performs QA |
| Custom | ~$1,500-$2,000+ | $100/mo | Bespoke presentation/components while staying on SLAI Web platform |
| Complex/exception | Quote | $100/mo + true variable costs where needed | Ecommerce, unusual integrations, high traffic, special infrastructure |

These are planning hypotheses until validated.

## Standard Platform Scope

Normally included with an active SLAI Web plan:

- hosting/SSL,
- dashboard,
- approved themes/layouts/pages/sections,
- preview/publish,
- version history/rollback,
- backups,
- technical platform maintenance,
- domain/DNS assistance,
- standard support,
- continued approved design-system updates,
- ServicesOS connector where applicable,
- bounded SLAI Intelligence assistance.

## Separately Scoped Work

Examples:

- bespoke layout,
- custom component,
- ecommerce,
- unusual third-party integration,
- large content-writing engagement,
- professional photography coordination,
- advanced animation,
- specialized data service,
- high-bandwidth/storage requirements,
- major redesign beyond supported self-service options.

## Pricing Principle

> Charge more when something creates real work, complexity, support burden, or variable cost — not merely because it is possible to invent another fee.
