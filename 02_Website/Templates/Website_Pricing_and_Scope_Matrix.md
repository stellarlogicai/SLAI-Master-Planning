# Website Pricing and Scope Matrix

**Status:** Working hypothesis template / current pricing authority  
**Last Updated:** 2026-09-15

## Current Planning Authority

For SLAI Web build/platform pricing, this file reflects the current working hypotheses.

Older references to a default ~$2,000 standard website build in historical planning should be treated as superseded by the current DIY / done-for-you / custom model below unless Jamie explicitly changes pricing again.

These are still planning hypotheses until real customers validate conversion, support burden, delivery time, and margins.

## Purpose

Keep SLAI Web pricing tied to actual scope, support burden, and variable cost rather than arbitrary complexity.

## Recurring Platform Pricing

SLAI Web V1 offers the same platform entitlement on either billing interval:

| Billing interval | Price | Effective monthly | Customer savings vs monthly |
|---|---:|---:|---:|
| Monthly | $100/month | $100.00 | — |
| Annual | $1,000/year | ~$83.33 | $200/year / two months free |

Monthly and annual customers receive the same normal V1 platform features and support class. The annual plan is a commitment/payment-frequency discount, not a separate feature tier.

## Build / Implementation Paths

| Path | Working Build Fee | Recurring | Intended Use |
|---|---:|---:|---|
| DIY | $0 | $100/mo or $1,000/yr | Customer uses guided onboarding/dashboard and builds within approved system |
| Done-for-you | ~$750-$1,000 | $100/mo or $1,000/yr | SLAI configures standard approved layout/sections and performs QA |
| Custom | ~$1,500-$2,000+ | $100/mo or $1,000/yr | Bespoke presentation/components while staying on SLAI Web platform |
| Complex/exception | Quote | $100/mo or $1,000/yr base + true variable costs where needed | Ecommerce, unusual integrations, high traffic, special infrastructure |

A one-time build/custom payment does not create lifetime hosting, editor access, support, or recurring platform entitlement.

## Standard Platform Scope

Normally included with an active SLAI Web plan:

- hosting/SSL,
- dashboard,
- approved themes/layouts/pages/sections,
- preview/publish,
- version history/rollback,
- backups,
- technical platform maintenance,
- domain/DNS assistance,
- standard support,
- continued approved design-system updates,
- ServicesOS connector where applicable,
- bounded SLAI Intelligence assistance.

## Separately Scoped Work

Examples:

- bespoke layout,
- custom component,
- ecommerce,
- unusual third-party integration,
- large content-writing engagement,
- professional photography coordination,
- advanced animation,
- specialized data service,
- high-bandwidth/storage requirements,
- major redesign beyond supported self-service options.

## Pricing Principle

> Charge more when something creates real work, complexity, support burden, or variable cost — not merely because it is possible to invent another fee.
